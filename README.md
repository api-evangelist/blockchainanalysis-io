BlockchainAnalysis.io provides a digital asset compliance platform that screens wallets, analyzes exchange accounts, monitors transactions, and offers regulatory context across 34 jurisdictions and 54 blockchains. The service includes KYT, AML, KYB, name and entity screening, and AI‑powered risk analysis for businesses handling crypto assets.

**Areas:** Company · Compliance · Blockchain · AML · KYT

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for BlockchainAnalysis.io: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
